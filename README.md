# Niur-DevTools

一个优雅的在线开发工具集，采用现代化设计，提供多种实用的开发辅助工具。

## 项目简介

Niur-DevTools 是一个基于纯前端技术栈构建的开发工具集合网站，采用苹果设计风格，提供了一系列简单、高效、优雅的在线开发工具。

### 特点

- 🎨 优雅的苹果风格界面设计
- 🌈 磨砂玻璃特效和现代化UI
- 💻 纯前端实现，无需后端
- 📱 完全响应式设计
- 🚀 支持离线使用
- 🎯 注重用户体验

## 技术栈

- HTML5
- CSS3 (使用现代特性如 backdrop-filter)
- Vanilla JavaScript
- 第三方库:
  - Marked.js (Markdown 解析)
  - Prism.js (代码高亮)
  - Bootstrap Icons (图标库)
  - browser-image-compression (图片压缩)

## 项目结构

```
niur-devtools/
├── assets/           # 静态资源文件
│   ├── css/         # 样式文件
│   ├── js/          # JavaScript 文件
│   └── icons/       # SVG 图标文件
├── tools/           # 工具集合
│   ├── markdown/    # Markdown 编辑器
│   ├── compress/    # 图片压缩工具
│   └── formatter/   # 代码格式化工具
└── index.html       # 主页面
```

## 功能说明

### 1. Markdown 编辑器
实时预览的 Markdown 编辑器，支持常用 Markdown 语法。

**特性：**
- 实时预览
- 代码高亮
- Terminal 风格代码块
- 导出为 HTML/PDF
- 文件拖放上传
- 空内容检查
- 一键复制功能
- 全屏模式支持

**使用方法：**
1. 在左侧编辑区输入 Markdown 文本
2. 右侧实时显示渲染结果
3. 使用工具栏按钮导出或保存
4. 导出 PDF 时使用浏览器打印功能，选择"另存为 PDF"

### 2. 图片压缩工具
在线压缩图片，支持批量处理。

**特性：**
- 支持 JPG/PNG/WebP/GIF 格式
- 批量处理（最多20张）
- 可调节压缩比例（10-90%）
- 实时预览对比
- 保持原图质量
- 一键下载
- 全屏预览
- 批量下载
- 放大镜预览效果
- 拖拽上传支持
- 实时压缩进度显示
- 智能压缩算法
- 保持图片EXIF信息
- 响应式布局设计

**使用方法：**
1. 选择或拖放图片（最多20张）
2. 调整压缩比例（数值表示要压缩掉的大小比例）
3. 点击"开始压缩"
4. 预览压缩效果
5. 单独下载或批量下载

**参数说明：**
- 压缩比例：10-90%（表示压缩掉原文件大小的���分比）
- 保持原始分辨率
- 保持EXIF信息
- 最大文件大小：50MB
- 支持的图片格式：JPG、PNG、WebP、GIF

**界面特点：**
- 磨砂玻璃效果背景
- 拖放区域动画效果
- 图片预览放大效果
- 压缩进度实时显示
- 文件大小对比显示
- 压缩比例实时预览
- 响应式布局适配

**技术实现：**
- 使用 browser-image-compression 库进行图片压缩
- 使用 HTML5 File API 处理文件
- 使用 Canvas API 进行图片处理
- 使用 CSS3 实现视觉效果
- 使用 Flexbox 和 Grid 布局
- 支持触摸设备操作

### 3. 格式转换工具
支持多种图片格式和 PDF 文件之间的相互转换。

**特性：**
- 支持格式：
  - 输入格式：JPG、PNG、WebP、GIF、PDF
  - 输出格式：JPG、PNG、WebP、GIF（PDF转换即将推出）
- 批量处理（最多20个文件）
- 实时预览
- 高质量转换
- 拖拽上传
- 一键下载
- 批量下载
- PDF 首页预览
- 响应式布局

**使用方法：**
1. 选择或拖放文件（支持多选）
2. 选择目标格式（JPG/PNG/WebP/GIF）
3. 点击"开始转换"
4. 预览转换效果
5. 下载转换后的文件

**技术特点：**
- 使用 Canvas API 进行图片格式转换
- 使用 PDF.js 处理 PDF 文件
- 本地转换，不上传服务器
- 保持原始图片质量
- 支持批量操作
- 实时预览功能

**参数说明：**
- 最大文件数：20个
- 单文件大小限制：50MB
- 支持的输入格式：
  - 图片：JPG、PNG、WebP、GIF
  - 文档：PDF（仅支持转为图片格式）
- 输出质量：
  - JPG/WebP：92% 质量
  - PNG：无损压缩
  - GIF：保持原始质量

**界面特点：**
- 简洁的拖放上传区域
- 清晰的格式选择选项
- 原图与转换后的对比预览
- 转换进度实时显示
- 批量下载按钮
- 文件信息显示（格式、大小、尺寸）
- 错误提示和状态反馈

**注意事项：**
1. PDF 文件目前仅支持转换第一页
2. 转换后的文件名会自动添加格式后缀
3. 批量转换时可能需要较长时间
4. 建议使用现代浏览器以获得最佳体验

## Git 提交规范

为了保持代码库的整洁和可维护性，我们采用以下提交规范：

### 提交类型
- `Feature:` 新功能
- `Fix:` 修复问题
- `Docs:` 文档更新
- `Style:` 代码格式调整
- `Refactor:` 代码重构
- `Test:` 测试相关
- `Chore:` 构建过程或辅助工具的变动

### 提交信息格式
```
<类型>: <简短描述>

<详细描述>

- 具体改动点1
- 具体改动点2
- 具体改动点3
```

### 分支管理
- `main`: 主分支，保持稳定
- `develop`: 开发分支
- `feature/*`: 功能分支
- `fix/*`: 修复分支

### 版本管理
- 使用语义化版本号：`主版本号.次版本号.修订号`
- 例如：v1.0.0, v1.1.0, v1.1.1

## 关键节点备份
建议在以下情况创建 Git 标签（tag）：
1. 完成主要功能模块
2. 发布新版本
3. 重大重构前
4. 重要 bug 修复后

示例：
```bash
# 创建带注释的标签
git tag -a v1.0.0 -m "第一个正式版本发布"

# 推送标签到远程
git push origin v1.0.0
```

## 常见问题

### Q: 工具可以离线使用吗？
A: 是的，首次访问后会自动缓存必要资源，支持离线使用。

### Q: 支持移动端使用吗？
A: 完全支持，界面采用响应式设计，在移动端也能获得良好体验。

### Q: 图片压缩是在本地进行的吗？
A: 是的，所有操作都在浏览器本地完成，不会上传到服务器。

### Q: 压缩后的图片质量如何？
A: 我们使用智能压缩算法，在保证视觉质量的同时最大化压缩比例。用户可以通过预览功能直观对比压缩效果。

### Q: 支持哪些图片格式？
A: 目前支持 JPG、PNG、WebP、GIF 格式的图片压缩。

### Q: 有文件大小限制吗？
A: 单个文件最大支持 50MB，批量处理最多支持 20 张图片。
