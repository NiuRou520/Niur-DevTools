# Niur-DevTools

一个优雅的在线开发工具集，采用现代化设计，提供多种实用的开发辅助工具。

## 项目简介

Niur-DevTools 是一个基于纯前端技术栈构建的开发工具集合网站，采用苹果设计风格，提供了一系列简单、高效、优雅的在线开发工具。

### 特点

- 🎨 优雅的苹果风格界面设计
- 🌈 磨砂玻璃特效和现代化UI
- 💻 纯前端实现，无需后端
- 📱 完全响应式设计
- 🚀 支持离线使用
- 🎯 注重用户体验

## 技术栈

- HTML5
- CSS3 (使用现代特性如 backdrop-filter)
- Vanilla JavaScript
- 第三方库:
  - PDF.js (PDF 处理)
  - jsPDF (PDF 生成)
  - browser-image-compression (图片压缩)
  - Bootstrap Icons (图标库)
  - JSZip (文件压缩)
  - Marked.js (Markdown 解析)
  - Prism.js (代码高亮)

## 功能说明

### 1. Markdown 编辑器
实时预览的 Markdown 编辑器，支持常用 Markdown 语法。

**特性：**
- 实时预览渲染
- 代码语法高亮
- Terminal 风格代码块
- 导出为 HTML/PDF
- 文件拖放上传
- 自动保存功能
- 一键复制功能
- 全屏编辑模式
- 黑暗主题支持
- 自定义样式
- 图片上传预览
- 快捷键支持
- 目录导航
- LaTeX 公式支持
- 表格编辑器
- 图表支持

**编辑功能：**
- 常用 Markdown 语法
- 标题（H1-H6）
- 列表（有序/无序）
- 任务列表
- 表格编辑
- 代码块（支持多种语言）
- 数学公式
- 图表绘制
- 链接和图片
- 引用块
- 分割线
- 脚注
- HTML 内联

**导出选项：**
- HTML（带样式）
- PDF 文档
- 纯文本
- 带格式复制
- 自定义主题导出

**使用方法：**
1. 在左侧编辑区输入 Markdown 文本
2. 右侧实时显示渲染结果
3. 使用工具栏按钮进行格式设置
4. 可以随时预览和导出
5. 支持文件拖放导入
6. 使用快捷键提高效率

**快捷键支持：**
- `Ctrl + B`: 加粗
- `Ctrl + I`: 斜体
- `Ctrl + K`: 插入链接
- `Ctrl + Shift + I`: 插入图片
- `Ctrl + L`: 插入列表
- `Ctrl + Shift + C`: 插入代码块
- `Ctrl + S`: 保存
- `F11`: 全屏模式
- `Esc`: 退出全屏

### 2. 图片压缩工具
在线压缩图片，支持批量处理。

**特性：**
- 支持格式：
  - 图片：JPG、PNG、WebP
  - 文档：PDF（保持原格式压缩）
- 批量处理（最多20张）
- 可调节压缩比例（10-90%）
- 实时预览对比
- 保持原图质量
- 一键下载
- 全屏预览
- 批量下载
- 放大镜预览效果
- 拖拽上传支持
- 实时压缩进度显示
- 智能压缩算法
- 保持图片EXIF信息
- 响应式布局设计

**PDF 压缩特性：**
- 保持原始 PDF 格式
- 支持多页面处理
- 智能处理长图页面
- 自动适应页面尺寸
- 保持图片比例
- 居中显示内容
- 优化压缩参数
- 实时压缩进度
- 支持大尺寸页面

**使用方法：**
1. 选择或拖放文件（最多20张）
2. 调整压缩比例（数值表示要压缩掉的大小比例）
3. 点击"开始压缩"
4. 预览压缩效果
5. 单独下载或批量下载

**参数说明：**
- 压缩比例：10-90%（表示压缩掉原文件大小的百分比）
- 保持原始分辨率
- 保持EXIF信息
- 最大文件大小：50MB
- PDF 页面最大尺寸：14400pt
- 支持的格式：
  - 图片：JPG、PNG、WebP
  - 文档：PDF

### 3. 格式转换工具
支持多种图片格式和 PDF 文件之间的相互转换。

**特性：**
- 支持格式：
  - 输入格式：JPG、PNG、WebP、GIF、PDF
  - 输出格式：JPG、PNG、WebP、GIF、PDF
- 批量处理（最多20个文件）
- 实时预览
- 高质量转换
- 拖拽上传
- 一键下载
- 批量下载
- PDF 智能页面适配
- 响应式布局

**使用方法：**
1. 选择或拖放文件（支持多选）
2. 选择目标格式（JPG/PNG/WebP/GIF/PDF）
3. 点击"开始转换"
4. 预览转换效果
5. 下载转换后的文件

**技术特点：**
- 使用 Canvas API 进行图片格式转换
- 使用 PDF.js 处理 PDF 文件
- 使用 jsPDF 生成 PDF 文件
- 智能页面尺寸适配
- 本地转换，不上传服务器
- 保持原始图片质量
- 支持批量操作
- 实时预览功能

**参数说明：**
- 最大文件数：20个
- 单文件大小限制：50MB
- 支持的输入格式：
  - 图片：JPG、PNG、WebP、GIF
  - 文档：PDF
- 输出质量：
  - JPG/WebP：92% 质量
  - PNG：无损压缩
  - GIF：保持原始质量
  - PDF：保持原始尺寸和比例

## 常见问题

### Q: 工具可以离线使用吗？
A: 是的，首次访问后会自动缓存必要资源，支持离线使用。

### Q: 支持移动端使用吗？
A: 完全支持，界面采用响应式设计，在移动端也能获得良好体验。

### Q: 图片压缩是在本地进行的吗？
A: 是的，所有操作都在浏览器本地完成，不会上传到服务器。

### Q: 压缩后的图片质量如何？
A: 我们使用智能压缩算法，在保证视觉质量的同时最大化压缩比例。用户可以通过预览功能直观对比压缩效果。

### Q: 支持哪些图片格式？
A: 目前支持 JPG、PNG、WebP、GIF 格式的图片压缩。

### Q: 有文件大小限制吗？
A: 单个文件最大支持 50MB，批量处理最多支持 20 张图片。
